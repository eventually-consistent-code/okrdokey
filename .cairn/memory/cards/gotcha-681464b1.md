Piping `npm test` through grep (`npm test | grep "Tests"`) masks the exit code — the pipeline reports grep's status, not vitest's. Vitest can print all-tests-passed AND fail the run on "Unhandled Errors" (unhandled promise rejections during tests); the grep-filtered view shows only the green count lines, so the failure ships and CI catches it first. Discipline: capture output to a file and check `$?` of the test command itself (`npm test > out.txt 2>&1; echo $?`), or grep for `Unhandled` alongside the count lines. Cost of the miss: a red CI run on main immediately after a "clean" ship.
